## Purpose

游戏会话定义单机 MVP 的完整对局生命周期：选边、抽题、逐题作答、即时反馈与共情指数计分，最终产出可分享的评级结果，让玩家在娱乐中完成一次换位思考。

## ADDED Requirements

### Requirement: 阵营选择与开局

玩家 SHALL 在开局前选择自己的阵营（男生/女生），系统 MUST 为其分发对向视角的题目，即男生答 `for-female` 题、女生答 `for-male` 题。

#### Scenario: 男生阵营开局

- **WHEN** 玩家选择"我是男生"并开始游戏
- **THEN** 系统 MUST 生成一局由 `for-female` 题目构成的对局

#### Scenario: 女生阵营开局

- **WHEN** 玩家选择"我是女生"并开始游戏
- **THEN** 系统 MUST 生成一局由 `for-male` 题目构成的对局

### Requirement: 作答与即时反馈

每题作答后系统 SHALL 立即揭示参考答案、判定对错并展示解析；未作答前 MUST 不允许进入下一题。

#### Scenario: 答对

- **WHEN** 玩家选中参考答案对应的选项
- **THEN** 系统 MUST 判定为答对、增加共情分，并展示解析后允许进入下一题

#### Scenario: 答错

- **WHEN** 玩家选中非参考答案的选项
- **THEN** 系统 MUST 判定为答错、不得分，并同样展示解析（答错时更需学习），允许进入下一题

### Requirement: 共情指数计分

答对一题得 100 基础分；连续答对 SHALL 触发连对加成（第 n 连对额外 +10×(n-1) 分，封顶 +50）。共情指数 MUST 等于实际得分占满分的百分比。

#### Scenario: 连对加成

- **WHEN** 玩家连续答对第 3 题
- **THEN** 该题得分 MUST 为 100 + 20 连对加成

#### Scenario: 连对中断清零

- **WHEN** 玩家答错一题
- **THEN** 连对计数 MUST 归零，下一题答对仅得 100 基础分

### Requirement: 结算与评级称号

对局结束时系统 SHALL 展示答对题数、共情指数与评级称号；称号 MUST 为正向幽默风格，不得使用贬低性称呼。结果页 MUST 提供"再来一局"与分享入口。

#### Scenario: 评级映射

- **WHEN** 对局结束共情指数为 80% 及以上
- **THEN** 系统 MUST 展示最高档称号（如"读心大师"），并为每个共情指数区间展示对应称号

#### Scenario: 再来一局

- **WHEN** 玩家在结果页点击"再来一局"
- **THEN** 系统 MUST 重新抽题开始新对局，且不重复上一局已出现的题目（题库允许范围内）

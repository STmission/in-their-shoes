# GDD — 《TA 的世界》In Their Shoes

> Game Design Document · v0.2 · Status: v1 已上线（H5 + 微信小程序双端）
> Owner: Design · Last updated: 2026-10-02

## 1. Vision / 一句话愿景

**让性别差异从"互相指责"变成"互相理解"。**

男生答女生的典型处境，女生答男生的典型处境。不比输赢，比"共情指数"——你越懂 TA，分数越高。

## 2. Design Pillars / 设计支柱

| 支柱           | 含义                           | 反例（我们不做）               |
| -------------- | ------------------------------ | ------------------------------ |
| **换位思考**   | 永远让玩家站在对面立场作答     | 让男生答男生题证明自己         |
| **幽默不冒犯** | 场景好笑但解析温柔，笑完有所得 | 用刻板印象当"标准答案"嘲笑某方 |
| **共情即分数** | 计分奖励理解而非知识储备       | 冷知识问答、记忆力考验         |
| **一分钟一局** | 单条小测 4 题约 1 分钟         | 长养成线、每日任务打卡         |

## 3. Target Audience

- 18-35 岁，情侣/朋友聚会/办公室破冰场景。
- 核心动机：社交谈资 + "测试你懂不懂我"的情侣互动。
- 平台习惯：微信生态分享裂变 + 浏览器即开即玩。

## 4. Core Loop / 核心循环

```
大厅选小测（场景×方向）→ 答对向视角题(4题) → 即时反馈+解析 → 结算共情指数 → 称号分享 → 再来一局
```

## 5. Game Modes

### 5.1 场景专场小测（当前唯一模式，单机）

- 大厅为「玩法库」列表：每个场景拆成两条入口——「她的处境·男生答」与「他的处境·女生答」，点哪条直接开局。
- 顶部 SMART PICK「随机全场景」为 8 题综合场，需先在底部弹层选阵营。
- 顶部 chips 可按「男生答 / 女生答」筛选。
- 每题四选一，作答后立即揭示参考答案 + 解析 + 平权小知识，约 2.6s 自动连跳下一题。
- 结算产出共情指数与称号。

### 5.2 后续模式（Roadmap）

- **双人同屏对战**：一部手机两人轮流作答，各答对方视角题，共情指数高者胜。
- **默契考验**：情侣双方各自答题后比对答案重合度（好友页好友码已预留入口）。
- **联机房间**：微信小程序房间对战。

## 6. Systems / 系统规则

### 6.1 共情指数（Empathy Index）

| 规则       | 数值                                        |
| ---------- | ------------------------------------------- |
| 答对基础分 | +100                                        |
| 连对加成   | 第 n 连对额外 +10×(n-1)，单题加成封顶 +50   |
| 答错       | +0，连对清零                                |
| 共情指数   | 实际得分 / 满分（全对且连对最大加成）× 100% |

### 6.2 评级称号（全部为正向幽默向，禁止贬低）

| 共情指数 | 男生侧称号      | 女生侧称号  |
| -------- | --------------- | ----------- |
| ≥ 90%    | 读心大师        | 读心大师    |
| 70–89%   | 懂王本王        | 知心姐姐    |
| 50–69%   | 潜力股暖男      | 默契养成中  |
| 30–49%   | 钢铁直男·进化中 | 直女·观察期 |
| < 30%    | 火星来客        | 金星访客    |

### 6.3 场景体系（12 场景 / 96 题 / 24 条小测）

| 分类 | 场景     | 主题                                  |
| ---- | -------- | ------------------------------------- |
| 沟通 | 聊天密语 | 回复节奏/潜台词解码                   |
| 沟通 | 吵架模式 | 洞穴沉默 vs 追根究底（火星金星梗）    |
| 沟通 | 情感需求 | 被需要/被崇拜 vs 被珍视/安全感        |
| 互动 | 约会现场 | 约会礼仪与信号                        |
| 互动 | 暧昧心事 | 暧昧期信号（优雅不露骨）              |
| 互动 | 计分法则 | 干大事计大分 vs 每件小事都计分        |
| 现实 | 消费观念 | 花钱观差异                            |
| 现实 | 未来蓝图 | 房车/孩子/工作/生活方式               |
| 现实 | 生活日常 | 日常习惯                              |
| 现实 | 情绪时刻 | 情绪表达与安抚                        |
| 娱乐 | 社交习惯 | 社交偏好                              |
| 娱乐 | 荧幕情感 | 影视剧名场面（1988/前任3/三十而已等） |

> 火星金星等主题为**娱乐化灵感来源**，不代表普适规律；解析一律注明"不代表所有人"。

### 6.4 皮肤系统（分身 × 陪测精灵）

- **分身**：Pixel Adventure 像素小人 4 款（Pink Man / Ninja Frog / Virtual Guy / Mask Dude），idle/run/jump/hit 帧动画。
- **陪测精灵**：ShadowPets 6 款 GIF（Luna/Frost/Nova/Comet/Felis/Draco），idle/bounce/greet。
- 阵营卡、答题舞台、计算过场、结果庆祝、我的页全程出场；答对 jump+bounce、答错 hit+greet。
- 「我的」页换装间双池独立选择，选择本地持久化。
- 素材均为开源授权，署名见 `docs/CREDITS.md`。

## 7. Content Guidelines / 内容准则（题库 PR 必过 checklist）

1. 场景可调侃，解析必温柔——笑点是处境，不是某一性别。
2. "参考答案"代表**常见反应统计**，解析中必须注明"不代表所有人"。
3. 禁止：外貌羞辱、能力贬损、地域/年龄歧视、把任一方描绘为"不讲理"、露骨性暗示。
4. 鼓励：双向场景配对（同一个处境出男女两版视角题）。
5. funFact 优先引用真实心理学/社会学概念（indirect communication、mental load 等）或注明出处为娱乐化借用。

## 8. UX / 交互要点

- 竖屏单手操作，主按钮位于屏幕下 1/3 拇指热区。
- 作答即反馈：答对绿色发光描边 + 连对火焰；答错红色描边，正确项绿色高亮。
- 结果页称号逐字弹入发光 + 共情指数渐变环 + 分享卡片弹层。
- 视觉主题「霓虹派对」：深紫底 #0A0812 + 环境光斑 + 蓝→紫→粉渐变强调，性别中立。
- 桌面 H5 以 430px 手机卡居中呈现，内容卡内滚动。
- 好友页（好友码/邀请/默契列表）与「我的」（记录/换装）当前为本地演示数据，无后端。

## 9. Success Metrics（接入埋点后启用）

- 完局率（开始 → 看到结果页）目标 ≥ 70%
- 分享率（结果页点击分享）目标 ≥ 15%
- 再来一局率 ≥ 30%

## 10. 合规

- 无账号无数据收集（当前纯本地存储）。
- 文案全程"仅供娱乐"声明，不作心理诊断/科学断言。
- 小程序提审类目建议：生活服务/娱乐，无支付无 UGC，过审风险低。

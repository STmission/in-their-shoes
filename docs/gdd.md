# GDD — 《TA 的世界》In Their Shoes

> Game Design Document · v0.1 · Status: MVP in development
> Owner: Design · Last updated: 2026-09-25

## 1. Vision / 一句话愿景

**让性别差异从"互相指责"变成"互相理解"。**

男生答女生的典型处境，女生答男生的典型处境。不比输赢，比"共情指数"——你越懂 TA，分数越高。

## 2. Design Pillars / 设计支柱

| 支柱           | 含义                            | 反例（我们不做）               |
| -------------- | ------------------------------- | ------------------------------ |
| **换位思考**   | 永远让玩家站在对面立场作答      | 让男生答男生题证明自己         |
| **幽默不冒犯** | 场景好笑但解析温柔，笑完有所得  | 用刻板印象当"标准答案"嘲笑某方 |
| **共情即分数** | 计分奖励理解而非知识储备        | 冷知识问答、记忆力考验         |
| **一分钟一局** | 单局 ≤ 5 分钟，随时开始随时分享 | 长养成线、每日任务打卡         |

## 3. Target Audience

- 18-35 岁，情侣/朋友聚会/办公室破冰场景。
- 核心动机：社交谈资 + "测试你懂不懂我"的情侣互动。
- 平台习惯：微信生态分享裂变 + 浏览器即开即玩。

## 4. Core Loop / 核心循环

```
选阵营 → 答对向视角题(N题) → 即时反馈+解析 → 结算共情指数 → 称号分享 → 再来一局
```

单局时长目标：8 题 × 约 20 秒 ≈ 3 分钟。

## 5. Game Modes

### 5.1 灵魂互换赛（MVP 唯一模式，单机）

- 玩家选择"我是男生 / 我是女生"。
- 男生阵营 → 抽取 `for-female` 题库（女生处境题）；女生阵营 → 抽取 `for-male` 题库。
- 每题四选一，作答后立即揭示参考答案 + 解析 + 平权小贴士。
- 结算产出共情指数与称号。

### 5.2 后续模式（Roadmap，不在 MVP）

- **双人同屏对战**：一部手机两人轮流作答，各答对方视角题，共情指数高者胜。
- **默契考验**：情侣双方各自答题后比对答案重合度。
- **联机房间**：微信小程序房间对战。

## 6. Systems / 系统规则

### 6.1 共情指数（Empathy Index）

| 规则       | 数值                                        |
| ---------- | ------------------------------------------- |
| 答对基础分 | +100                                        |
| 连对加成   | 第 n 连对额外 +10×(n-1)，单题加成封顶 +50   |
| 答错       | +0，连对清零                                |
| 共情指数   | 实际得分 / 满分（全对且连对最大加成）× 100% |

### 6.2 评级称号（全部为正向幽默向，禁止贬低）

| 共情指数 | 男生侧称号      | 女生侧称号  |
| -------- | --------------- | ----------- |
| ≥ 90%    | 读心大师        | 读心大师    |
| 70–89%   | 懂王本王        | 知心姐姐    |
| 50–69%   | 潜力股暖男      | 默契养成中  |
| 30–49%   | 钢铁直男·进化中 | 直女·观察期 |
| < 30%    | 火星来客        | 金星访客    |

## 7. Content Guidelines / 内容准则（题库 PR 必过 checklist）

1. 场景可调侃，解析必温柔——笑点是处境，不是某一性别。
2. "参考答案"代表**常见反应统计**，解析中必须注明"不代表所有人"。
3. 禁止：外貌羞辱、能力贬损、地域/年龄歧视、把任一方描绘为"不讲理"。
4. 鼓励：双向场景配对（同一个处境出男女两版视角题）。
5. funFact 优先引用真实心理学/社会学概念（ indirect communication、mental load 等）。

## 8. UX / 交互要点

- 竖屏单手操作，主按钮位于屏幕下 1/3 拇指热区。
- 作答即反馈：答对绿色脉冲 + 连对火焰提示；答错红色抖动但解析文案安慰性呈现。
- 结果页称号大号视觉 + 共情指数环形图 + 分享按钮。
- 性别中立配色：双色对抗（蓝 #4F7CFF × 粉 #FF6B9D）融合为主紫 #7C5CFF，避免纯粉/纯蓝刻板。

## 9. Success Metrics（接入埋点后启用）

- 完局率（开始 → 看到结果页）目标 ≥ 70%
- 分享率（结果页点击分享）目标 ≥ 15%
- 再来一局率 ≥ 30%

## 10. 合规

- 无账号无数据收集（MVP 纯本地）。
- 小程序提审类目建议：生活服务/娱乐，无支付无 UGC，过审风险低。

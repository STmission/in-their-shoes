# 原型设计 —《TA 的世界》

> 可运行原型 = `pnpm dev:h5` 启动的 H5 版本，即 MVP 本体。
> 本文档描述三屏线框、设计 token 与交互流。设计稿基准：375×812 竖屏。

## 设计 Token

| Token         | 值        | 用途                     |
| ------------- | --------- | ------------------------ |
| `--c-primary` | `#7C5CFF` | 主色（蓝粉融合的中性紫） |
| `--c-boy`     | `#4F7CFF` | 男生阵营色               |
| `--c-girl`    | `#FF6B9D` | 女生阵营色               |
| `--c-correct` | `#3ECF8E` | 答对                     |
| `--c-wrong`   | `#FF5C5C` | 答错                     |
| `--c-bg`      | `#14121F` | 深色底（游戏感）         |
| `--c-card`    | `#1E1B2E` | 卡片底                   |
| radius        | 16px      | 卡片/按钮圆角            |
| font-display  | 32px/700  | 标题                     |
| font-body     | 16px/400  | 正文                     |

## 屏 1：首页 Home

```
┌─────────────────────────┐
│                         │
│      TA 的世界 🌍        │  ← 主标题（emoji 待美术替换）
│   你有多懂对面的世界？    │  ← 副标题
│                         │
│  ┌─────────┐┌─────────┐ │
│  │ 🙋‍♂️    ││ 🙋‍♀️    │ │  ← 阵营选择卡(单选高亮描边)
│  │ 我是男生 ││ 我是女生 │ │
│  └─────────┘└─────────┘ │
│                         │
│  ┌───────────────────┐  │
│  │   开始换位挑战 →   │  │  ← 主CTA，选中阵营后点亮
│  └───────────────────┘  │
│                         │
│   男生答女生题 · 女生答男生题 │  ← 玩法一句话说明
└─────────────────────────┘
```

交互：点选阵营 → 卡片描边发光（阵营色）→ CTA 点亮 → 点击进对局页。

## 屏 2：对局 Quiz

```
┌─────────────────────────┐
│ ◄ 3/8      ▓▓▓░░░░░  🔥2│  ← 进度条 + 题序 + 连对火焰
│                         │
│ ┌─────────────────────┐ │
│ │ 女生说「随便，都行」  │ │  ← 场景卡
│ │ 的时候通常意味着……  │ │
│ └─────────────────────┘ │
│                         │
│ ┌─────────────────────┐ │  ← 选项按钮×4，整行可点
│ │ A. 真的随便          │ │
│ ├─────────────────────┤ │
│ │ B. 有偏好但想让你猜  │ │
│ ├─────────────────────┤ │
│ │ C. 在考验你的默契    │ │
│ ├─────────────────────┤ │
│ │ D. 想吃火锅          │ │
│ └─────────────────────┘ │
│                         │
│ (作答后)                │
│ ✓ 答对! +120  🔥连对x3   │  ← 即时反馈条
│ ┌─────────────────────┐ │
│ │ 💡 解析: ...         │ │  ← 解析卡 + funFact
│ │ 小知识: ...          │ │
│ └─────────────────────┘ │
│  ┌───────────────────┐  │
│  │     下一题 →       │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

交互：选项点击 → 该选项变绿/红、正确项高亮 → 反馈条滑入 → "下一题"按钮出现。答错时卡片轻微抖动动画。

```
┌─────────────────────────┐

│  │    再来一局        │  │

```

## 页面流转

```
Home ──选阵营+开始──▶ Quiz ──答完N题──▶ Result ──再来一局──▶ Quiz(重新抽题)
                                              └─回到首页──▶ Home
```

## 无障碍与降级

- 所有可点元素 ≥ 44pt 触控热区。
- 对错不只依赖颜色：附 ✓/✗ 图标与文案。
- H5 分享降级：`navigator.share` → `clipboard` → 提示手动复制。

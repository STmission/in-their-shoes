# 原型设计 —《TA 的世界》

> 可运行原型 = `pnpm dev:h5` 启动的 H5 版本，即产品本体。
> 本文档描述五屏结构、设计 token 与交互流。设计基准：430px 宽竖屏手机卡。

## 设计 Token（霓虹派对 Neon Party）

| Token    | 值                                                        | 用途                   |
| -------- | --------------------------------------------------------- | ---------------------- |
| 底色     | `#0A0812` + 蓝/粉/紫 radial 光斑                          | 全局夜场底             |
| 卡片     | `rgba(255,255,255,.05)` + 细描边                          | 玻璃卡                 |
| 强调卡   | 紫→粉渐变 + `rgba(124,92,255,.5)` 光晕                    | 推荐大卡/好友码/角色卡 |
| 主按钮   | `linear-gradient(92deg,#5f8bff,#b15cff,#ff6b9d)` + 紫光晕 | 全部主 CTA             |
| 答对     | `#3ECF8E` 发光描边                                        | 选项/判定              |
| 答错     | `#FF5F6D` 发光描边                                        | 选项/判定              |
| 强调文字 | `#CDCBFF`                                                 | 标签/徽章/激活态       |
| 阵营色   | 蓝 `#5F8BFF` × 粉 `#FF6B9D`                               | 换位专场标签           |
| radius   | 14–20px                                                   | 卡片/按钮圆角          |
| 弹层     | `#171426` 圆角顶弹 + 紫描边                               | 全部底部 sheet         |

> 双端约束：不用 `backdrop-filter`/`filter:blur`；光斑用 radial-gradient，像素帧动画用
> 裁剪容器 + `translateX steps(N-1)`（位移 -(N-1)/N，杜绝末尾空帧）。

## 屏 4：好友（演示数据）

好友码卡（紫粉渐变 + 精灵 + 复制）→ 邀请条 → 搜索 → 好友列表（头像 + 上次测试 + 默契%渐变数字）→ 「+ 添加」弹层输 6 位好友码。

## 屏 5：我的

角色卡（当前分身+精灵+最近称号+去挑战）→ 三项统计（累计/最高指数/题库数）→ 换装间（双池网格选择器，选中蓝光描边）→ 测试记录列表 → 免责与素材署名。

```
 └─tabBar──▶ 好友 / 我的
```

## 无障碍与降级

- 所有可点元素 ≥ 44pt 触控热区。
- 对错不只依赖颜色：附 ✓/✗ 文案与字母键色块。
- 桌面 H5：430px 居中手机卡（`min(920px, 94vh)`），transform 建立包含块使弹层/tabBar 收于卡内。
- 小程序：`page` 选择器承载深色底；H5 需 `!important` 覆盖 `.taro_router > .taro_page` 默认白底。
